# AI usage disclosure

This NeoForge 1.21.1 port was developed with AI coding assistance. AI involvement included writing and modifying implementation code, investigating compatibility and gameplay issues, assisting with debugging and validation, and preparing documentation. It was not limited to spelling, formatting or suggestions.

OpenAI Codex is the assistant used in the development workflow documented here. A complete inventory of historical tools, model versions, prompts and generated lines has not been retained in this repository. This disclosure is based on the available development notes and repository history; it does not assign a verified percentage of the code to AI.

## Original work and port changes

The project derives from Simply Skills 1.7.2 for Fabric 1.20.1 by Sweenus and Timefall Development, as credited in the [project README](README.md). Inherited code, gameplay designs and assets remain attributable to their original authors under the [existing license](LICENSE). Their presence in an AI-assisted port does not make them AI-generated.

The port contains inherited implementation alongside AI-assisted additions, adaptations, fixes and refactors. There is no reliable line-by-line record separating human-written, AI-generated and subsequently edited code. Git authorship identifies the account recording a change, not who or what composed each line. Reviewers should consider the port changes broadly within the AI-assisted development scope; the examples below are a review map, not an exhaustive authorship ledger.

## Human involvement and verification limits

The maintainer directed requested changes, reported problems, performed in-game checks and supplied visual/gameplay observations recorded in the [verification notes](review/verification.md). AI-assisted development also used build results and debugger observations. These are different kinds of evidence; neither a successful build nor AI review proves all gameplay paths correct. The records do not establish a complete independent human review of every changed line.

Packaged dedicated-server startup and focused two-player checks passed at the scopes recorded in the [verification notes](review/verification.md). Multiplayer testing found a shared Rapidfire shot counter; the fix passed post-restart runtime verification, and the rebuilt JAR passed standalone-server startup. The planned focused release smoke checks are complete; optional deeper coverage and lower-priority code review are described in the [release review](review/release-review.md). This disclosure summarizes those results and does not establish additional runtime validation or a review of every code path.

The previously tracked `AGENTS.md` contained assistant workflow instructions; it was removed from the review branch and is not an authorship record. Private handoffs, worlds, runtime configurations and debugger state are not required to read the [public review documentation](review/README.md). Keep this disclosure current as additional authorship information becomes available or the scope of AI use changes.
